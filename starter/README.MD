# Workshop 01 - Personal Webpage

This project is a simple, responsive personal website built as part of Workshop 01. It covers core web development concepts, including semantic HTML structure, custom CSS styling, dynamic card layouts, and responsive media queries.

## Workshop Overview

By completing this project, the following features were implemented:
- **A structured HTML page** with semantic sections (`header`, `nav`, `main`, `section`, `footer`)
- **Custom CSS styling** with custom typography, colors, and layouts
- **A navigation menu** linking to different page sections
- **A contact form** styled with modern input elements
- **Responsive design** optimized for tablet and mobile screens

---

## Features & Completed Challenges

In addition to the core tasks, the following bonus features have been completed:

1. **Grid Layout for "About" Section:**
   - Implemented a CSS Grid layout (`.about-grid`) displaying content in responsive cards that adapt dynamically to screen size.
   - Added hover animations and dynamic card styling.

2. **Smooth Scrolling:**
   - Added `scroll-behavior: smooth;` to the global styles, ensuring fluid transitions when navigating via menu links.

---

## How to View

1. **Clone or Download** this repository to your local machine.
2. **Open `index.html`** in your preferred web browser (e.g., Chrome, Firefox, Safari).

## Testing & Validation

The website has been tested and validated using the following methods:
- Tested across multiple browsers (Chrome, Firefox, Safari) and screen sizes using browser DevTools.
- HTML validated with the [W3C HTML Validator](https://validator.w3.org/).
- CSS validated with the [W3C CSS Validator](https://jigsaw.w3.org/css-validator/).
